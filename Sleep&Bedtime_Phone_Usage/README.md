# Sleep & Bedtime Screen-Time Analytics Dashboard

![Dashboard Preview](/Images/db_bedtime-1.png)

An interactive analytics dashboard that explores the relationship between **bedtime phone usage**, **sleep quality**, and demographic factors such as occupation, age group, gender, and chronotype.


![Dashboard Preview](/Images/db_bedtime-2.gif)
---

## 📊 Project Overview

This dashboard analyzes screen-time habits before bed and their impact on sleep metrics across **9,000 users**.  
It helps identify patterns in phone usage, sleep debt, deep sleep, fatigue, and caffeine intake.

### Key Metrics (Overall)

| Metric                        | Value |
|-------------------------------|-------|
| Total Users                   | 9K    |
| Avg. Bedtime Phone Use        | 59 min|
| Avg. Sleep Duration           | 6 hr  |
| Avg. Deep Sleep               | 22 min|
| Avg. Sleep Latency            | 41 min|

---

## 🔍 Dashboard Insights

### 1. Who Uses the Phone Most Before Bed?
- **Occupation**: Corporate 9-to-5 workers lead with the highest usage.
- **Age Group**: Young Adults show the highest bedtime phone usage.
- **Gender**: Females (51%) slightly higher than Males (46%).

### 2. Chronotype & Bedtime Usage
- Morning Larks and Intermediate types have slightly higher average bedtime usage (~60 min) compared to Night Owls (~58 min).

### 3. Top Bedtime Apps
| App                    | Avg. Usage (min) |
|------------------------|------------------|
| Instagram / Reddit     | 61               |
| News / Reading         | 60               |
| TikTok / Reels         | 60               |
| Messaging / Chat       | 59               |
| YouTube                | 58               |
| Streaming (Netflix/Hulu)| 57              |

TikTok / Reels has the highest number of users (2,198).

### 4. Sleep Debt Distribution
- **Moderate Debt**: 4.5K users (largest group)
- Mild Deficit: 2.0K
- Optimal Recovery: 1.4K
- Severe Sleep Debt: 0.6K

### 5. Other Key Findings
- **Healthcare / Shift Workers** snooze alarms the most.
- Fatigue scores are highest among **Young Adults** (3.9).
- Users with **Severe Sleep Debt** have the highest caffeine intake (52g) and lowest sleep hours (4h).
- Deep sleep is consistent (~22 min) across occupations, while physical activity varies slightly.

## 📌 Key Takeaways

- Young adults and corporate workers are the heaviest bedtime phone users.
- Social media apps (TikTok, Instagram, Reddit) dominate bedtime screen time.
- Higher caffeine intake is strongly associated with severe sleep debt.
- Deep sleep remains relatively stable across occupations, while overall sleep duration varies significantly.
